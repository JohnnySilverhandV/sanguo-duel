# sanguo-duel · 三国格斗原型

三国题材 2D 对战的**可玩技术原型**：关羽（玩家）对赵云（AI），**单文件 HTML、零依赖、无构建**，双击即玩。画面是火柴人，重点在帧数据表、三框判定与打击感，不在美术。

- 固定 60 逻辑帧循环，逻辑与渲染分离，掉帧不影响判定

## ✨ 功能

| 模块 | 说明 |
|---|---|
| 战斗核心 | 固定步长主循环，accumulator 累积，渲染可插值 |
| 动作系统 | 帧数据表 + 状态机；idle / walk / crouch / attack / hit / ko 各自规则 |
| 判定 | 每逻辑帧取双方当前帧的框列表，两两 AABB 相交 |
| 指令识别 | 输入缓冲，`↓↓ + 轻击` 在 24 帧窗口内匹配成必杀 |
| 多段判定 | 命中记录按帧号去重，同一帧只结算一次 |
| AI | 逼近、按距离出招、命中后追击 |
| 调试 | `F1` 判定框、`F2` 帧数据、`P` 暂停后 `.` 逐帧 |

## 🚀 使用

直接用浏览器打开 `index.html`，或用上面的在线入口。

| 操作 | 按键 |
|---|---|
| 移动 / 下蹲 | `A` `D` / `S` |
| 轻击 | `J` |
| 必杀（↓↓ + 轻击） | 连按两下 `S`，再按 `J` |
| 判定框可视化 | `F1` |
| 帧数据面板 | `F2` |
| 暂停 / 重开 | `P` / `R` |
| 暂停时逐帧前进 | `.` |
| 调试：直接释放关羽 / 赵云大招 | `K` / `L` |

URL 参数可预设调试状态：`?boxes` 开判定框、`?data` 开帧数据、`?nodim` 暂停遮罩减淡。组合示例：`index.html?boxes&data&nodim`。

**已知缺失**：防御系统未做，AI 的三段连刺只能硬吃；双人本地对战、音效、回合流程均未实现。这是刻意的范围控制。

## 🛠 技术要点

- **逻辑时钟唯一**：所有计时以逻辑帧为单位，与显示器刷新率无关。60Hz 与 144Hz 屏幕上判定完全一致。
- **判定的最小粒度是逻辑帧，不是图片**。帧数据表按图索引，因此「命中帧」那张图的 `duration` 必须精确等于该招的 `activeFrames`；否则一张图停 4 帧会吞掉只有 2 帧的判定窗口，表现为「有时打得中有时打不中」。
- **表现与判定解耦**：判定框是纯数据，跟贴在上面的是立绘还是色块无关。换美术只改渲染层，判定一行代码都不用动——这正是灰盒先行的意义。
- **多段技靠帧号去重**：单个布尔值 `hasHit` 会把多段技压成一段，必须按帧记录。
- **特效层不参与判定**，且不受 hitstop 影响，否则打击瞬间的视觉反馈会被冻结吞掉。
